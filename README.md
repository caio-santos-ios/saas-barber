# saas-barber

Documentação do SaaS **APP Barbearia + Web (Versão 1)** — sistema de agendamentos para barbearias.

## Sobre o projeto

Este projeto consiste em um SaaS de agendamentos para barbearias composto por um aplicativo mobile (Flutter) e uma plataforma web (Angular), com backend em .NET, banco de dados MongoDB, pagamentos via Asaas e notificações/auth via Firebase. O plano padrão custa R$ 39,99/mês.
